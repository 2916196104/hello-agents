# chapter9 项目组织结构结论

chapter9 是《上下文工程》章节的示例集合，工作目录被指定为 my_flask_app（当前为空）。

组织方式：
1. 顶层教学示例脚本（01~06）：ContextBuilder / NoteTool / TerminalTool / 三天工作流
2. codebase_maintainer.py：核心组件，CodebaseMaintainer 类，整合 ContextBuilder+NoteTool+TerminalTool+MemoryTool，采用 Agentic 模式（FunctionCallAgent 自主决策工具）
3. codebase/：示例被维护的代码库（data_processor.py, api_client.py, utils.py, models.py, __init__.py），含 TODO 供分析演示
4. data/sales_2024.csv：演示数据
5. project/：TerminalTool 安全特性演示（白名单、工作目录限制、路径逃逸保护）
6. my_flask_app_notes/：NoteTool 工作区，notes_index.json 为空
7. my_flask_app/：目标项目目录，空

维护助手运行时产物：{project_name}_notes 工作区、maintainer_report_{session_id}.json
