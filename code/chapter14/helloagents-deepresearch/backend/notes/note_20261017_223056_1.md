# 任务 2: AI Agent岗位市场需求

核心问题：AI Agent相关岗位的市场需求变化趋势
检索方向：
1. 2026年AI岗位招聘数据
2. AI Agent工程师/开发者需求统计
3. 企业AI Agent团队规模变化
4. 招聘平台AI Agent岗位数量趋势

预期产出：岗位需求量化分析，判断市场扩张或收缩信号

【新增分析】
1. 2026年AI Agent相关岗位招聘量同比增长超300%，2025年AI相关岗位月均新发职位数同比增长率高达74%
2. AI Agent开发相关岗位薪资较去年同期上涨35%，59.6%岗位月薪超25K，北京平均突破40K
3. 岗位需求激增317%，AI工程师中位数薪资涨幅15.8%
4. 软件项目经理需求增长了15倍，年薪涨了71%
5. 82%的组织计划到2026年集成AI Agent，到2027年50%的企业将部署AI Agent
6. 中国AI岗位初级岗位占比未出现类似美国的持续萎缩趋势，初级岗位占比稳定在7%左右
7. AI技能岗位内部，开发岗占近三分之二，但应用岗一年之间几乎翻了一番
8. 全球到2030年预计创造1.7亿个新岗位，同时让9200万个岗位变得多余
9. 美国因AI明确裁撤的岗位数量5.5万，但AI岗位同比增长36%
10. 中国AI岗位中高级岗位占比从2024年一季度的63.18%降至2025年二季度的60.87%
